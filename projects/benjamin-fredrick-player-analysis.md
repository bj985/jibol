# Benjamin Fredrick Player Analysis
### Statistical profiling supported by separate video observations

[Back to project hub](../README.md) · [Portfolio](https://ibrahimbolaji.framer.website/)

**Tools:** PostgreSQL · Tableau · Once Sport  
**Project type:** Independent individual-player case study

## The question

What does the player's statistical profile show, and which questions should be investigated through match observation?

The project uses Belgian Pro League data for performance profiling and separate Nigeria match footage for tagged video analysis. These are complementary sources, not one pooled competition sample.

## What I built

An individual-player analysis combining SQL-based performance profiling, Tableau visuals and tagged sequences in Once Sport. The work connects player data with written football observations while keeping the context of each evidence source visible.

| Evidence stream | Role in the analysis | Boundary |
| --- | --- | --- |
| Club and league data | Describe performance and provide a peer-comparison setting | A league comparison is not automatically a forecast of performance elsewhere |
| Nigeria match footage | Examine actions and decisions in specific sequences | National-team observations should not be presented as footage from the Belgian league |
| Written interpretation | Connect the numerical profile with questions for further observation | Separate directly observed actions from hypotheses and recommendations |

## Reading the profile responsibly

Use minutes, role and team context alongside defensive metrics. High clearance or tackle volume can reflect how much defending a team is required to do. Aerial activity and aerial success should be considered separately.

A tagged clip can illustrate a behaviour, but one sequence does not establish how frequently it occurs. Any report should label the match, date and observation sample, and distinguish an observed strength from a topic needing more evidence.
