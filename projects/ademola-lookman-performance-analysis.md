# Ademola Lookman Performance Analysis
### Goal threat, creativity and attacking contribution

[Back to project hub](../README.md) · [Portfolio](https://ibrahimbolaji.framer.website/)

**Tools:** Power BI · Excel  
**Project type:** Individual-player performance dashboard

## The question

How can an attacking player's contribution be described beyond goals and assists?

This dashboard examines Lookman's finishing, expected goals, passing, chance creation, dribbling, crossing and wider attacking contribution across the seasons and competitions represented in the source data.

## What I built

An interactive two-page Power BI analysis, with source data prepared in Excel. The project connects attacking output with the actions that contribute to chance creation. FootyStats was used as a data source in this project.

| Dimension | What the comparison is intended to reveal |
| --- | --- |
| Goals and expected goals | Output alongside the quality of recorded chances |
| Shooting | Attempts, accuracy and conversion context |
| Assists and expected assists | Creative contribution alongside recorded outcomes |
| Passing and crossing | Ways of advancing attacks and supplying teammates |
| Dribbling | Ball-carrying activity and successful take-ons |
| Season and competition filters | Changes in the recorded performance profile |

## Interpretation guide

Use minutes and competition filters consistently. Per-90 output and season totals answer different questions, and short samples require caution.

Expected goals and expected assists depend on provider definitions. A comparison should use compatible data rather than combining measures from different models without documentation. Conversion percentages must state their denominators.

The goal is a clear attacking profile, not a claim that one dashboard fully explains tactical fit, off-ball movement or future performance.
